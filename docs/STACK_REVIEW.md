# Stack review for November 2026

- **FastAPI 0.165.0 and Python 3.14.** Use ASGI lifespan to own PostgreSQL and Redis clients. Authenticate WebSocket upgrades before accepting them, validate message bodies separately, and keep reconnect messages in an AsyncAPI contract alongside the HTTP OpenAPI export. [Release notes](https://fastapi.tiangolo.com/release-notes/#01650-2026-11-18) · [Lifespan](https://fastapi.tiangolo.com/advanced/events/) · [WebSockets](https://fastapi.tiangolo.com/advanced/websockets/)
- **Rust 1.100.0 and PyO3.** Keep rules and simulation in the pure Rust crate. Call the engine through a thin binding that releases the GIL around independent native compute. Use the pinned production toolchain in CI and validate with the November stable toolchain locally. [Rust release](https://blog.rust-lang.org/2026/11/12/Rust-1.100.0/) · [PyO3 performance](https://pyo3.rs/main/performance.html)
- **Redis and PostgreSQL.** Use Redis Lua for version checks, ownership and event commits. PostgreSQL owns durable results and reward settlement in an idempotent transaction. [Redis scripting](https://redis.io/docs/latest/develop/programmability/eval-intro/) · [SQLAlchemy asyncio](https://docs.sqlalchemy.org/en/21/orm/extensions/asyncio.html)
- **Gemini and applied AI.** Keep structured output separate from game facts and validate it against engine-derived inputs. Keep text and speech out of the turn path and test provider behavior with stand-ins. Review speech model names and output format against the provider documentation when configuring a deployment. [Structured output](https://ai.google.dev/gemini-api/docs/structured-output) · [Speech generation](https://ai.google.dev/gemini-api/docs/speech-generation) · [Pydantic AI testing](https://ai.pydantic.dev/testing/)
